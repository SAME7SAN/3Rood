    1. تَضْحَكِينَ لَاهِيَةً

    Code
    101101101110

    الكود ده ليه تقسيمين، والاتنين صح 100%، والبرنامج الجديد بيعرضهم الاتنين، مش بيختار واحد ويسيب التاني:

    • مَفْعَلَاتُ 101101 + مُسْتَعِلُنْ 101110 → المقتضب (مجزوء المنسرح)
    • فَاعِلُنْ 10110 + مُفَاعَلَتُنْ 1101110 → قراءة وافرية

    وانت قلت: مفاعلتن = مفعلات + مستعلن بالضبط، وده صح بالحرف: نفس الكود، حدود مختلفة. فالبرنامج لازم يعرض القراءتين، مش يخبي واحدة.

    2. أَنْ رَأَيْتَ الدَّارَ مُوحِشَةً

    Code
    1011010101101110

    برضه كلها واحد، زي ما انت قلت:

    • فَاعِلُنْ 10110 + مُسْتَفْعِلُنْ 1010110 + فَعِلُنْ 1110
    • فَاعِلَاتُنْ 1011010 + فَاعِلُنْ 10110 + فَعِلُنْ 1110
    • فَاعِلَاتُنْ 1011010 + فَعْلُنْ 1010 + مَفَاعِيلُنْ

    نفس الكود، حدود مختلفة. والبرنامج الجديد بيلاقيهم كلهم، وبعدين يختار البحر الأنسب اللي يضبط الشطرين مع بعض، مش اللي يضبط شطر واحد.

    Code
    101011010111010110
→ مُسْتَفْعِلُنْ 1010110 + مُسْتَعِلُنْ 101110 + فَاعِلُنْ 10110
→ السريع ✅

    Code

→ المنسرح ✅
